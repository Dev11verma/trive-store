# TRIOX

TRIOX is a limited-drop oversized streetwear brand.

## Run the website

Open index.html in your browser.

## Run the backend

```powershell
cd backend
npm install
npm start
```

Backend URL:

http://localhost:3000

## GitHub Pages

Upload index.html, styles.css, and script.js if you use separate files.

For this version, upload only index.html.

Go to Settings > Pages > Deploy from a branch > main > / (root).
