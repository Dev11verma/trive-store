# TRIOX — Streetwear Store

A lightweight, GitHub Pages-ready landing page for TRIOX.

## Run locally

1. Save these files in one folder.
2. Open `index.html` in any browser.

## Publish on GitHub Pages

1. Create a GitHub repository named `triox-site`.
2. Upload `index.html`, `styles.css`, and `script.js`.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`.
6. Save. Your site will appear at `https://YOUR-USERNAME.github.io/triox-site/`.
